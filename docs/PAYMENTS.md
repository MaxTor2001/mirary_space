# Подключение оплаты через ЮKassa

Пошаговый список того, что нужно сделать вам. Код приёма платежей уже написан и ждёт ключей:
как только вы пришлёте данные из последнего раздела, оплата включится без доработок.

Почему ЮKassa: одно подключение закрывает и приём денег (карты, СБП, SberPay), и онлайн-кассу
по 54-ФЗ, и не требует переводить расчётный счёт в конкретный банк. Основную часть платежей
уводим на СБП — комиссия по нему не выше 0,7% против примерно 3% за карты.

## Шаг 1. Подготовить документы

| Что нужно | Пояснение |
|---|---|
| ИП или ООО | Самозанятость для перепродажи украшений не подходит |
| ИНН, ОГРН/ОГРНИП | Выписка из ЕГРИП/ЕГРЮЛ — скачивается на сайте ФНС бесплатно |
| Паспорт руководителя или ИП | Скан разворота с фото и страницы с пропиской |
| Расчётный счёт | Любой банк, реквизиты со справки из банка |
| Система налогообложения | УСН «доходы», УСН «доходы минус расходы», ОСН — точная формулировка нужна для чеков |

## Шаг 2. Привести сайт к требованиям модерации

ЮKassa проверяет сайт вручную и заворачивает заявку, если чего-то не хватает. Что должно быть:

| Требование | Состояние на mirari.space |
|---|---|
| Описание товаров и цены | Есть — каталог |
| Условия доставки | Есть — /delivery |
| Условия возврата | Есть — /delivery, блок про 14 дней |
| Реквизиты продавца (наименование, ИНН) | Есть — /about и /contacts, **но проверьте, что данные настоящие** |
| Настоящие контакты: телефон, email, адрес | **Сейчас стоят выдуманные** — «+7 (999) 123-45-67», «ул. Пирсинговая, 7» |
| Публичная оферта (договор с покупателем) | Есть — /offer, требует вашей проверки |
| Политика обработки персональных данных | Есть — /privacy, требует вашей проверки |
| HTTPS | Есть, сертификат Let's Encrypt |

От вас нужны:

1. **Настоящие контакты** — телефон, email, адрес (или город и режим работы, если пункта выдачи нет).
2. **Реквизиты ИП** — полное наименование и ИНН, как в документах.
3. Проверку страниц **оферты** (`/offer`) и **политики персональных данных** (`/privacy`) —
   они уже опубликованы по типовым текстам с вашими реквизитами. Отвечает за их содержание
   владелец магазина: покупатель заключает договор именно с ним.

Замену контактов делаю я, по вашим данным.

## Шаг 3. Зарегистрироваться в ЮKassa

1. Открыть https://yookassa.ru и нажать «Подключить».
2. Заполнить анкету: данные ИП/ООО, реквизиты счёта, адрес сайта `https://mirari.space`,
   описание — «интернет-магазин украшений для пирсинга».
3. Подписать оферту в личном кабинете (электронно, кодом из СМС).
4. Дождаться модерации: обычно 1–3 рабочих дня. Если завернут — в письме будет причина,
   присылайте её мне.

## Шаг 4. Подключить онлайн-кассу

По 54-ФЗ на каждый онлайн-платёж нужно пробить чек и отправить его покупателю и в налоговую.
Штраф за непробитый чек — от 3 000 ₽. Варианты:

- **Облачная касса от ЮKassa** — аренда в личном кабинете, чеки формируются сами по данным,
  которые сайт передаёт вместе с платежом. Рекомендую: подключается в пару кликов, отдельный
  договор с ОФД не нужен.
- Своя касса или касса другого сервиса — тоже можно, но тогда пришлите её реквизиты
  подключения, интеграция будет другой.

При подключении кассы вас спросят систему налогообложения и ставку НДС — записывайте ответы,
их нужно будет передать мне (см. последний раздел).

## Шаг 5. Включить способы оплаты

В личном кабинете, раздел со способами оплаты, включите:

- **СБП** — обязательно, это самый дешёвый способ, сделаем его первым в списке;
- **Банковские карты** «Мир», Visa, Mastercard;
- **SberPay** и **ЮMoney** — по желанию, они бесплатны для вас в подключении.

Рассрочку и «Долями» на старте включать не советую: они добавляют комиссию и правила возвратов.

## Шаг 6. Забрать ключи

В личном кабинете: раздел **Интеграция → Ключи API**.

1. Скопируйте **shopId** — идентификатор магазина, число.
2. Выпустите **секретный ключ** (Secret Key) — строка вида `live_...`. Показывается один раз,
   сохраните сразу.
3. Там же есть **тестовый магазин** с отдельной парой ключей (`test_...`). Сначала подключим
   его: проверим оплату без настоящих денег.
4. В разделе **Интеграция → HTTP-уведомления** укажите адрес
   `https://mirari.space/api/payments/webhook/` и включите события `payment.succeeded` и
   `payment.canceled`. Адрес уже работает на сайте.

## Что прислать мне

- [ ] **Тестовые** shopId и секретный ключ (`test_...`) — с них начнём
- [ ] **Боевые** shopId и секретный ключ (`live_...`) — когда тест пройдёт
- [ ] Систему налогообложения (например, «УСН доходы»)
- [ ] Ставку НДС для товаров (у большинства ИП на УСН — «без НДС»)
- [ ] Подключена ли облачная касса ЮKassa
- [ ] Настоящие контакты и реквизиты для сайта (шаг 2)

Ключи — это доступ к вашим деньгам. Не выкладывайте их в переписку, где попало, и не коммитьте
в репозиторий: на сервере они лягут в `.env` с правами 600, как остальные секреты. Если удобнее —
впишите их в `.env` сами, я покажу, куда именно, и в чат они не попадут.

## Что уже сделано

1. Приложение `payments` в бэкенде: платёж создаётся в ЮKassa при оформлении заказа, позиции
   с толщиной и длиной уходят в чек для облачной кассы.
2. На странице оформления — выбор способа: «онлайн картой или через СБП» либо «при получении».
   Онлайн-вариант появляется, только когда в `.env` заданы ключи.
3. Обработчик HTTP-уведомлений `/api/payments/webhook/`: оплата подтверждается не по телу
   уведомления, а перечитыванием платежа в API ЮKassa — подделать уведомление нельзя.
4. Платежи видны в админке: сумма, статус, идентификатор в ЮKassa и заказ.
5. Если оплата не прошла или покупатель закрыл форму, заказ сохраняется, а на его странице
   остаётся кнопка «Оплатить» — платёж можно повторить.

## Что останется после получения ключей

Вписать в `.env` на сервере четыре строки и перезапустить сайт:

```
YOOKASSA_SHOP_ID=идентификатор магазина
YOOKASSA_SECRET_KEY=секретный ключ
YOOKASSA_VAT_CODE=1              # 1 — без НДС
YOOKASSA_SEND_RECEIPT=1          # 0, если облачная касса ещё не подключена
```

Дальше — тестовый заказ на боевых ключах и возврат его денег из личного кабинета ЮKassa.
Работы на полчаса; отдельного дня разработки, как планировалось раньше, уже не нужно.
