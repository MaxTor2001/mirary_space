# Индексация, Метрика и поисковая выдача

Что уже работает на сайте и что осталось сделать руками в панелях Яндекса и Google.

## Уже сделано в коде

| Что | Адрес / где смотреть |
|---|---|
| `robots.txt` с закрытыми личными разделами | https://mirari.space/robots.txt |
| Карта сайта: страницы, категории, все товары | https://mirari.space/sitemap.xml |
| `description`, `canonical`, Open Graph на каждой странице | `frontend/views/partials/seo.ejs` |
| Свои заголовки и описания у категорий и товаров | `frontend/src/routes/goods.js` |
| `noindex` на страницах ошибок | `frontend/src/server.js` |
| Счётчик Метрики (включается номером в `.env`) | `frontend/public/js/metrika.js` |
| Подтверждение владения для Яндекса и Google | переменные `*_VERIFICATION` |
| IndexNow: ключ отдаётся сайтом, отправка скриптом | `frontend/scripts/indexnow.js` |

Карта сайта собирается из каталога на лету: новые товары попадают в неё сами,
отдельный список вести не нужно.

## Что нужно сделать руками

Все четыре пункта сводятся к одному: получить значение в чужой панели и записать
его в `.env` на сервере. Как применять — в конце.

### 1. Яндекс.Вебмастер — чтобы сайт вообще попал в индекс

1. https://webmaster.yandex.ru → «Добавить сайт» → `https://mirari.space`
2. Способ подтверждения — **мета-тег**. Скопировать значение `content` из
   предложенного тега (длинная строка вида `a1b2c3d4e5f6`).
3. Записать в `.env`: `YANDEX_VERIFICATION=<значение>`, применить (см. ниже).
4. Вернуться в Вебмастер, нажать «Проверить».
5. После подтверждения: «Индексирование» → «Файлы Sitemap» → добавить
   `https://mirari.space/sitemap.xml`.

### 2. Яндекс.Метрика — статистика посещений

1. https://metrika.yandex.ru → «Добавить счётчик», сайт `mirari.space`.
2. Взять **номер счётчика** (8 цифр). Код копировать не нужно, он уже в проекте.
3. Записать в `.env`: `YANDEX_METRIKA_ID=<номер>`, применить.
4. Проверить: `curl -s https://mirari.space/ | grep metrika` — должен появиться
   тег `<script src="/js/metrika.js" data-id="...">`.

Запись сессий (вебвизор) намеренно выключена в `metrika.js`: на оформлении
заказа посетитель вводит имя, телефон и адрес, писать это в запись незачем.
Если понадобится — правится строка `webvisor: false`.

### 3. Google Search Console

1. https://search.google.com/search-console → «Add property» → **URL prefix** →
   `https://mirari.space`
2. Способ — **HTML tag**, скопировать значение `content`.
3. Записать в `.env`: `GOOGLE_SITE_VERIFICATION=<значение>`, применить, нажать «Verify».
4. Sitemaps → добавить `sitemap.xml`.

### 4. IndexNow — уже настроен

Ключ сгенерирован и лежит в `.env` (`INDEXNOW_KEY`), сайт отдаёт его по адресу
`https://mirari.space/<ключ>.txt`. Яндекс и Bing протокол поддерживают, Google — нет.

Запускать после того, как реально что-то поменяли — добавили товары, поправили
тексты. На потоке лишних уведомлений поисковик начинает их игнорировать.

```bash
ssh fstek 'cd /home/deploy/mirari && docker exec \
  -e SITE_URL=https://mirari.space \
  -e INDEXNOW_KEY=$(grep "^INDEXNOW_KEY=" .env | cut -d= -f2) \
  mirari-frontend node scripts/indexnow.js'
```

Без аргументов отправляются все адреса из карты сайта; можно указать конкретные:
`node scripts/indexnow.js /catalog /product/titanovyy-labret`.

Ответ `202 Accepted` — принято. `403` — ключ не совпадает с тем, что отдаётся
по адресу ключа. `422` — в списке адреса с чужого домена.

## Как применить изменения в `.env`

```bash
ssh fstek
cd /home/deploy/mirari
nano .env                 # вписать значения
docker compose -f docker-compose.yml -f docker-compose.prod.yml -p mirari up -d
```

Пересборка не нужна: переменные читаются при старте контейнера.

## Важное про сроки и содержимое

**Каталог сейчас пустой** — демо-товары удалены, а `SEED_DEMO=0` не даст им
вернуться. Отправлять сайт на индексацию имеет смысл после того, как появятся
настоящие товары: пустой магазин в индексе даёт страницы без содержимого, и
переиндексация потом занимает недели.

Разумный порядок: сначала товары → потом пункты 1 и 3 → потом IndexNow.

Первое появление в выдаче на новом домене — от нескольких дней до пары недель
у Яндекса и дольше у Google. Карта сайта и IndexNow ускоряют обход, но не
гарантируют позиции.
